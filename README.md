# PyTrace - Python トレース学習支援システム

**PyTrace（TraceApp）** は、Python プログラミング初学者がプログラムの実行順序や変数の値の変化、アルゴリズムの構造（流れ図）を視覚的に理解・学習できる **Web アプリケーション** です。

ブラウザの WebAssembly（Pyodide）技術を活用し、サーバーレスかつ安全な環境で Python コードのトレース実行と流れ図の自動生成を行います。ビルド後は **単一の HTML ファイル（オフライン完全対応）** として配布・利用可能です。

---

## 🌟 主な機能と特徴

### 1. ヘッダー集中型 ステップ実行ナビゲーション & コードエディタ
- **上部ヘッダーへの操作統合**: 「トレース準備」「最初」「前へ」「次へ」「最後」ボタンおよびステップシークバーをヘッダーに集約し、視線移動少なく快適にトレースを進行。
- **トグル式タブバー**: 「コード（Python ⇄ マクロ言語）」のセグメントスイッチと「流れ図」タブをワンクリックで切り替え。
- **作業領域の最大化**: 下部フッターを撤廃し、Monaco Editor および流れ図が画面下端まで 100% 広がるフルハイトレイアウト。
- **スマート自動相互変換 & 流れ図同期**: タブを切り替えるだけで Python ⇄ マクロ言語（VBA）を自動相互変換。マクロ言語を編集して流れ図タブを開いた場合もバックグラウンドで自動逆変換・流れ図生成・トレース再実行。
- **サンプル選択 & ズームスライダー**: タブバー右側に「サンプル選択」「拡大率（50%〜400%）」を集約。
- **フローティング「.py読込」ボタン**: Python エディタ右上に半透明ブラー背景のファイル読込ボタンを配置（Python タブ表示時のみ表示）。

### 2. スプレッドシート型 変数履歴表
- 変数名を横軸、各ステップの推移を縦軸に並べた見やすい表形式で表示。
- 直前ステップから **値が変化したセルおよび列全体を自動ハイライト**。
- **コメント表示**: 行末コメント（例: `# (ア)`）のある行が実行されて値が変化した際、値の右隣にコメントバッジを表示（流れ図と共通の構文解析で一元管理）。
- **拡大率スライダー（50%〜400%）**: ヘッダー右端にズームバーを配置し、エディタとは独立して変数履歴表全体を等比率でズーム可能。
- **自動スクロール追従**: ステップ進行（「次へ」「最後」「シークバー操作」等）に合わせて、最新のアクティブ行・変更セルが画面外にある場合は自動でスムーズスクロール。
- **「変更のない行を非表示」フィルター**: 値が変化した重要なステップのみに絞り込んで確認できます。

### 3. Python コードからの流れ図（フローチャート）自動生成
- Python の AST（抽象構文木）を解析し、プログラム構造に応じた標準記号で流れ図を自動描画：
  - **順次・代入処理**: 長方形（累加代入 `a += 2` は `a ＋ 2 → a` に展開表示）
  - **条件分岐 (if / elif / else)**: ひし形（Yes / No 分岐、複数ブロックの整列配置、共通合流線）
  - **繰り返し (while / for)**: 六角形（ループ開始／終了記号）
  - **関数定義・サブルーチン**: 二重線長方形・端子
- **行末コメントのアノテーション表示**: 命令行末尾の `# (ア)` などのコメントを抽出し、ブロック横（条件分岐は右下）に自動配置。
- **ステップ連動ハイライト**: トレース実行に合わせて、現在実行中の流れ図ブロックが自動でハイライトされます。
- **ズーム機能**: 50% 〜 400% の拡大縮小に対応。

### 4. マクロ言語（VBA）相互変換 & 連動エディタ
- **Python ⇄ マクロ言語（VBA）双方向変換**: ワンクリックで Python コードとマクロ言語コードを相互変換。
- **実用的なVBA構文生成**: `Sub Program() ... End Sub` ラップ、`Dim` による変数一括型宣言、独立した `Function` / `Sub` 配置、引数・戻り値型アノテーション対応。
- **ステップ実行行の完全連動**: マクロ言語タブ表示時も、Python トレース実行に合わせて現在実行行が Monaco Editor 上でリアルタイムにハイライト。
- **統一されたキーワードハイライト**: `If`, `Then`, `For`, `Do While`, `Sub`, `MsgBox` 等の構文キーワードを統一された青色で明瞭表示。

### 5. ブラウザ内 WebAssembly (Pyodide) による高速・安全な実行エンジン
- ブラウザ上の Python 実行環境（Pyodide / WebAssembly）で高速かつ安全にインメモリ実行。
- **無限ループ防止ガード**: 10,000 ステップ上限超過（`TraceLimitExceeded`）によるブラウザフリーズ防止。
- **構文エラー・実行時例外の安全ハンドリング**: 初心者がコードを間違えてもクラッシュせず、わかりやすいエラーメッセージを表示。

## 🚀 開発・利用手順

### 前提条件
- Node.js (v18 以上推奨)
- npm または yarn

### インストールと開発サーバー起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev
```

### ビルド（単一 HTML ファイルの生成）
```bash
# dist/index.html に単一のポータブル HTML が出力されます
npm run build
```

生成された `dist/index.html` は、Web サーバーを介さずブラウザで直接ダブルクリックして開くことができ、ネットワーク接続がない環境でも動作します。
