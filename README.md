# PyTrace - Python トレース学習支援システム

**PyTrace（TraceApp）** は、Python プログラミング初学者がプログラムの実行順序や変数の値の変化、アルゴリズムの構造（流れ図）を視覚的に理解・学習できる **Web アプリケーション** です。

ブラウザの WebAssembly（Pyodide）技術を活用し、サーバーレスかつ安全な環境で Python コードのトレース実行と流れ図の自動生成を行います。ビルド後は **単一の HTML ファイル（オフライン完全対応）** として配布・利用可能です。

---

## 🌟 主な機能と特徴

### 1. ステップ実行ナビゲーション & コードエディタ
- **1行ごとの双方向ステップ移動**: 「最初」「前へ」「次へ」「最後」ボタンにより、実行順序を自由に行き来できます。
- **ステップスライダー**: 全ステップ中の現在位置を可視化し、ドラッグで任意のステップへ瞬時にジャンプできます。
- **Monaco Editor 連動**: 現在実行中の行がエディタ上でリアルタイムにハイライトされます。
- **ファイル読み込み**: 直接のコード編集に加え、ローカルの `.py` ファイルのアップロード読込に対応しています。

### 2. スプレッドシート型 変数履歴表
- 変数名を横軸、各ステップの推移を縦軸に並べた見やすい表形式で表示。
- 直前ステップから **値が変化したセルおよび列全体を自動ハイライト**。
- **「変更のない行を非表示」フィルター**: 値が変化した重要なステップのみに絞り込んで確認できます。

### 3. Python コードからの流れ図（フローチャート）自動生成
- Python の AST（抽象構文木）を解析し、プログラム構造に応じた標準記号で流れ図を自動描画：
  - **順次・代入処理**: 長方形（累加代入 `a += 2` は `a ＋ 2 → a` に展開表示）
  - **条件分岐 (if / elif / else)**: ひし形（Yes / No 分岐、複数ブロックの整列配置、共通合流線）
  - **繰り返し (while / for)**: 六角形（ループ開始／終了記号）
  - **関数定義・サブルーチン**: 二重線長方形・端子
- **行末コメントのアノテーション表示**: 命令行末尾の `# (ア)` などのコメントを抽出し、ブロック横（条件分岐は右下）に自動配置。
- **ステップ連動ハイライト**: トレース実行に合わせて、現在実行中の流れ図ブロックが自動でハイライトされます。
- **ズーム機能**: 50% 〜 400% の拡大縮小に対応。

### 4. Web Worker + Pyodide による高速・安全な実行エンジン
- Python 実行環境（Pyodide）を **Web Worker** 上で分離実行し、UI の応答性を常に維持。
- **無限ループ防止ガード**: 10,000 ステップ上限超過（`TraceLimitExceeded`）によるブラウザフリーズ防止。
- **構文エラー・実行時例外の安全ハンドリング**: 初心者がコードを間違えてもクラッシュせず、わかりやすいエラーメッセージを表示。

## 📚 プリセット学習サンプル

起動後、画面上部のドロップダウンから即座に学習用コードを選択できます：

1. **1. 基本的な順次・代入**: 変数の代入、四則演算、計算結果の出力
2. **2. 条件分岐**: `if` / `elif` / `else` による数値評価と多分岐判定
3. **3. ループと関数**: 関数定義・呼び出しと `for` ループによる累積処理

## 🚀 開発・利用手順

### 前提条件
- Node.js (v18 以上推奨)
- npm または yarn

### インストールと開発サーバー起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev
```

### ビルド（単一 HTML ファイルの生成）
```bash
# dist/index.html に単一のポータブル HTML が出力されます
npm run build
```

生成された `dist/index.html` は、Web サーバーを介さずブラウザで直接ダブルクリックして開くことができ、ネットワーク接続がない環境でも動作します。
